## 9. 汇总评分

|---|---|---|
| ★★★★★ | CPSC（美国） | 数据最完整，API/RSS 支持，接入难度最低 |
| ★★★★★ | RAPEX（欧盟） | 覆盖27国，欧盟强制通报 |

| ★★★★☆ | ACCC（澳大利亚） | 英文，结构化程度高 |
| ★★★★☆ | KEMCO/KATS（韩国） | 亚洲重要市场 |
| ★★★★☆ | METI/CAA（日本） | 日本市场必备 |
| ★★★☆☆ | OPSS（英国） | 英国脱欧后独立系统 |

## 10. 接入建议

### 第一期（高优先级，4 个）
1. **CPSC** — RSS/API，英文，数据最规范
2. **RAPEX/Safety Gate** — HTML 列表，英文，欧盟全覆盖
3. **DPAC** — HTML 列表，中文，中国市场核心
4. **ACCC** — HTML/RSS，英文，澳洲数据

### 第二期（中等优先级，4 个）
5. **OPSS（英国）**
6. **KEMCO/KATS（韩国）**
7. **METI/CAA（日本）**
8. **Health Canada（加拿大）**

### 第三期（低优先级，视需求）
9. 巴西 INMETRO
10. 台湾 BSMI
11. 重庆/广东/上海地方局
12. IEC 国际标准数据
