## 四、数据库初始化步骤

### 4.1 初始化数据库

```python
from whyfxpg.core.db import init_db

# 默认初始化（创建所有表）
init_db()

# 指定数据库路径
init_db('path/to/whyfxpg.db')
```

### 4.2 初始化因果知识库

```python
from whyfxpg.core.causal_knowledge import init_causal_schema, CausalKnowledge

# 初始化因果图谱 Schema
init_causal_schema()

# 播种初始因果知识
ck = CausalKnowledge()
result = ck.seed_initial_knowledge()
print(result)
```

### 4.3 数据库迁移

```python
from whyfxpg.migrations import MigrationRunner
from whyfxpg.core.db import get_db_connection

conn = get_db_connection()
runner = MigrationRunner(conn)
runner.run()
conn.commit()
conn.close()
```

### 4.4 配置加载与环境变量覆盖（P07）

Phase 1 起业务配置（risk_model / dimensions / alert_rules）经 **Pydantic 校验**后加载：

- **加载链路**：YAML → 环境变量覆盖 → Pydantic 校验 → 配置模型
  （`whyfxpg/config/pydantic_models.py` + `pydantic_loader.py`）
- **拒绝启动**：结构性错误（缺 `version`、`severity_levels` 为空等）抛
  `ConfigValidationError`，错误信息包含具体字段路径
- **环境变量覆盖**：`RISK_MODEL__<字段路径>`，嵌套路径用 `__` 分隔，
  值按 JSON 解析（数字/布尔/列表），失败按字符串处理。例如：

  ```bash
  # 覆盖 risk_model.yaml 的 history_factor.max
  export RISK_MODEL__HISTORY_FACTOR__MAX=1.8
  # 覆盖阈值
  export RISK_MODEL__RISK_LEVEL_THRESHOLDS__S=90
  ```

- **降级策略**：单字段校验失败或缺省时使用该字段默认值，不影响整体启动

## 六、配置文件说明

### 6.1 配置文件位置

| 配置文件 | 路径 | 说明 |
|---------|------|------|

```python

loader = ConfigLoader(DEFAULT_CONFIG_DIR)
risk_model = loader.risk_model       # risk_model.yaml
alert_rules = loader.alert_rules     # alert_rules.yaml
```

## 七、常见问题

### 7.1 数据库被锁定

**症状**：`sqlite3.OperationalError: database is locked`

**解决**：
```python
from whyfxpg.core.db import get_db_connection
conn = get_db_connection()
conn.execute("PRAGMA busy_timeout=10000")  # 增加等待超时
```

### 7.2 Streamlit 页面不刷新

**解决**：在终端中按 `Ctrl+C` 停止服务，然后重新 `streamlit run`。

### 7.3 依赖缺失

**症状**：`ModuleNotFoundError`

**解决**：
```bash
pip install streamlit pandas pyyaml requests
```
