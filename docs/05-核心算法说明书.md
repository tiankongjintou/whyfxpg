## 一、多维风险评分算法

### 1.1 评分公式

`risk_scorer.py` 中的 `RiskScorer.score()` 方法实现：

```
综合风险分 = exp( log(SS) + log(PS)
                  + log(country_factor) + log(product_factor)
                  + log(history_factor) + log(evidence_factor)
                  + log(causal_factor) )
```

即对数化公式 **`log_score = Σ log(1 + factor)`**：每个乘法项 f 的对数贡献为
`log(f) = log(1 + (f - 1))`（factor = f - 1 为该系数相对 1 的增量），
最后 `exp` 还原。数学上与旧公式 `SS × PS × ... × causal_factor` 完全等价，
但中间过程不经过乘积，**极端权重下不会溢出或失真**（TD01, 2026-08-11）。
边界语义：系数 = 1（增量 factor = 0）时 `log(1+0)=0` 不贡献；任一系数 ≤ 0
（无物理意义）时整体按 0 处理，与旧公式乘以 0 一致。

**归一化（P1b-03, 2026-08-11）**：`total_score`（0-10000+ 量纲）经单调映射
`normalized = 100 × total / (total + C)` 归一到 0-100（C 默认 3000，可用模型
配置 `normalization_constant` 覆盖）。`map_to_risk_level` 使用归一化分查阈值
（S≥85/M≥70/L≥50），与需求书 0-100 语义对齐；归一化前 0-10000+ 量纲直接套用
阈值会把轻微事件（≈1425 分）误判最高危。典型分布（C=3000）：
轻微×可能(≈1425)→32、中×可能(≈5700)→65、严重×可能(≈9025)→75、
严重×可能×因果2(≈17885)→86。`total_score` 字段保留原量纲（向后兼容），
`ScoringResult` 新增 `normalized_score` 字段。

其中：
- **SS（严重度分）**：基于 `severity_level` 字段，通过 `severity_to_score()` 查量表得到 0-100 的分数
- **PS（概率分）**：基于 `probability_level` 和 `country_history_count`，通过 `probability_to_score()` 得到 0-100 的分数
- **country_factor（国别系数）**：查 `risk_model.yaml` 中的 `country_factors` 映射表，默认 1.0
- **product_factor（品类系数）**：查 `risk_model.yaml` 中的 `product_factors` 映射表，默认 1.0
- **history_factor（历史系数）**：基于 `event_count_12m`（12个月内同类事件数）计算，公式来自 `risk_model.yaml` 中的 `history_factor.formula`
- **evidence_factor（证据系数）**：基于 `source_id` 查 `evidence_factors` 映射表，默认 0.9
- **causal_factor（因果因子）**：由 `CausalKnowledge.get_causal_factor()` 计算的外部因果增强系数

def history_factor(self, event_count_12m: int) -> float:
    formula = self._cfg.history_factor.formula  # 如 "1 + min(event_count_12m * 0.1, 0.5)"
    value = eval(formula, {"__builtins__": {"min": min, "max": max}}, 
                 {"event_count_12m": event_count_12m})
    return max(min_val, min(value, max_val))  # 夹断到 [min, max] 范围

### 1.3 风险等级映射

```python
def map_to_risk_level(self, total_score: float) -> str:
    if total_score >= thresholds.get("S", 8000):  # ≥8000 → S
        return "S"
    elif total_score >= thresholds.get("M", 3000):  # ≥3000 → M
        return "M"
    elif total_score >= thresholds.get("L", 1000):  # ≥1000 → L
        return "L"
    else:
        return "A"
```

> ⚠️ 注意：阈值在 risk_model.yaml 中配置，当前默认 S≥8000, M≥3000, L≥1000。但需求书中定义的分值区间为 S≥85, M≥70-84, L≥50-69, A<50，代码中的阈值与需求书不一致。

## 二、反馈学习引擎算法

### 2.1 学习触发条件

`FeedbackLearner` 类（`feedback_learner.py`）实现：

```python
MIN_REVIEWS_FOR_LEARNING = 5      # 至少5条修正才触发学习
CONSISTENCY_THRESHOLD = 0.70      # 修正一致性阈值（超过半数同向）
CLIPPING_THRESHOLD = 0.05        # 修正幅度阈值（5%以上才调整）
LEARNING_RATE = 0.20             # 每次学习调整20%的差距
```

### 2.2 国别系数学习

```python
def analyze_country_learning(self, grouped) -> List[Dict]:
    for country, reviews in grouped.items():
        if len(reviews) < MIN_REVIEWS_FOR_LEARNING:
            continue
        
        # 统计 rs_level 降级修正比例
        downgrades = sum(1 for r in reviews 
                        if rs_score(adjusted_rs) < rs_score(model_rs))
        consistency = downgrades / len(reviews)
        
        if consistency >= CONSISTENCY_THRESHOLD:
            avg_adjustment = average((adjusted_ss - original_ss) / original_ss)
            if abs(avg_adjustment) >= CLIPPING_THRESHOLD:
                # 计算新系数 = 当前系数 - avg_adjustment × LEARNING_RATE
                new_factor_delta = -avg_adjustment * LEARNING_RATE
```

**学习结果应用到 risk_model.yaml**：
```python
new_val = max(0.5, min(2.0, current + delta))  # 夹断到 [0.5, 2.0]
```
